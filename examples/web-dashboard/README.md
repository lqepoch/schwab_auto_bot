# 📈 Schwab API 股票数据可视化仪表板

一个基于 ECharts 的实时股票数据可视化Web应用，将Schwab API的流式数据以美观的图表形式展示。

## ✨ 功能特性

### 📊 实时数据可视化
- **股票概览卡片** - 显示价格、涨跌幅、成交量
- **实时价格趋势图** - 多股票价格走势对比
- **成交量柱状图** - 各股票成交量对比
- **系统统计面板** - 数据更新次数、运行时间等

### 🔄 实时数据流
- **WebSocket连接** - 实时推送数据更新
- **自动重连** - 网络断开时自动恢复连接
- **连接状态指示** - 直观显示API连接状态
- **数据缓存** - 保持历史数据用于图表展示

### 🎨 现代化UI
- **深色主题** - 护眼的深色界面设计
- **响应式布局** - 适配桌面和移动设备
- **动画效果** - 平滑的数据更新动画
- **状态指示器** - 实时连接状态显示

## 🚀 快速开始

### 1. 启动仪表板服务器

```bash
# 开发模式启动（推荐）
npm run dashboard

# 或者编译后启动
npm run dashboard:build
```

### 2. 访问Web界面

打开浏览器访问：**http://localhost:3000**

### 3. 默认监控股票

仪表板默认监控以下股票：
- **QQQ** - 纳斯达克100 ETF
- **SPY** - 标普500 ETF  
- **AAPL** - 苹果公司
- **TSLA** - 特斯拉
- **NVDA** - 英伟达

## 📱 界面说明

### 主要组件

1. **顶部状态栏**
   - 🟢 绿色：API连接正常
   - 🔴 红色：API连接断开
   - 🟡 黄色：API连接错误

2. **股票概览区域**
   - 显示每只股票的实时价格
   - 涨跌金额和百分比
   - 当日累计成交量
   - 颜色编码：绿色(上涨)、红色(下跌)、灰色(持平)

3. **系统统计面板**
   - 数据更新次数
   - 监控股票数量
   - 系统运行时间
   - 连接客户端数

4. **价格趋势图**
   - 多条线图显示各股票价格走势
   - 支持缩放和平移
   - 鼠标悬停显示详细信息

5. **成交量分析图**
   - 柱状图对比各股票成交量
   - 渐变色彩效果
   - 实时数据更新

## ⚙️ 技术架构

### 后端服务器
- **Express.js** - Web服务器框架
- **Socket.IO** - WebSocket实时通信
- **Schwab API** - 股票数据源

### 前端界面
- **ECharts** - 专业图表库
- **Socket.IO Client** - 实时数据接收
- **原生JavaScript** - 轻量级实现
- **CSS Grid/Flexbox** - 现代化布局

### 数据流程
```
Schwab API → Node.js服务器 → WebSocket → 浏览器 → ECharts图表
```

## 🔧 自定义配置

### 修改监控股票

编辑 `server.ts` 文件中的 `defaultSymbols` 数组：

```typescript
const defaultSymbols = ['QQQ', 'SPY', 'AAPL', 'TSLA', 'NVDA'];
```

### 调整服务器端口

修改 `server.ts` 中的端口设置：

```typescript
private port = 3000; // 改为你想要的端口
```

### 自定义图表样式

在 `index.html` 中修改 ECharts 配置：

```javascript
// 修改颜色主题
echarts.init(element, 'dark'); // 可改为其他主题

// 自定义颜色
itemStyle: {
    color: '#你的颜色代码'
}
```

## 📊 数据字段说明

### Level 1 股票数据包含：
- **symbol** - 股票代码
- **price** - 最新成交价
- **volume** - 累计成交量
- **change** - 涨跌金额
- **changePercent** - 涨跌百分比
- **bid/ask** - 买一价/卖一价
- **high/low** - 最高价/最低价
- **open** - 开盘价

## 🐛 故障排除

### 常见问题

1. **页面显示"连接中..."**
   - 检查Schwab API认证是否正确
   - 确认网络连接正常
   - 查看控制台错误信息

2. **图表不显示数据**
   - 确认股票代码正确
   - 检查市场开盘时间
   - 验证API权限设置

3. **频繁重连**
   - 检查网络稳定性
   - 尝试增加心跳超时时间
   - 关闭VPN或代理

### 调试模式

启动时添加调试输出：

```bash
DEBUG=* npm run dashboard
```
